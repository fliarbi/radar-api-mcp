Make your first request

Radar API (base URL ):

curl "$RADAR_API_URL/v1/companies/profile" \
  -H "Authorization: Bearer $FLIAR_API_KEY" \
  -H 'Content-Type: application/json' \
  -d '{"domain":"emudhra.com"}'

Connect an HTTP MCP client to with the same authorization header.

Prism News API, same key:

curl -sS --get "$PRISM_NEWS_URL/v1/headlines" \
  -H "X-API-Key: $FLIAR_API_KEY" \
  --data-urlencode 'q=electric vehicle' --data-urlencode 'limit=10'

Prism Business News API, same key:

curl -sS --get "$PRISM_BUSINESS_NEWS_URL/v1/business/funding" \
  -H "X-API-Key: $FLIAR_API_KEY" \
  --data-urlencode 'sector=fintech' --data-urlencode 'sort=amount' --data-urlencode 'limit=10'

Prism API & MCP, same key (MCP at ):

curl -sS -X POST "$PRISM_URL/v1/research.evidence" \
  -H "Authorization: Bearer $FLIAR_API_KEY" -H 'Content-Type: application/json' \
  -d '{"claim":"Metformin reduces cancer risk"}'

Credits per Prism feature: GET $PRISM_URL/v1/pricing. Check Prism News limits and usage with GET /v1/me on the News API.

One wallet pays for every API. Prism: 1–50 prepaid credits per call depending on the feature (quick counts 1, evidence reading 20, full articles 50); failed or empty answers cost nothing. Radar: one credit per successful data operation (briefs up to seven, comparisons up to three per company); your Radar plan's included credits are used first. Prism News: after your Prism News plan's monthly allowance, one credit per request and one per full-text article delivered. Failed requests are refunded. Prepaid spending stops at your monthly limit.

A limit of zero disables prepaid spending. No automatic recharge.
